[yoke run] execute the loop

USAGE: yoke run [--dry-run] [--no-sandbox] [--summary-fd N]
       yoke pause | resume | stop
       yoke inject [--shutdown] <message>

OPTIONS:
  --dry-run       Run one iteration without invoking OMP
                  (boundary check + configured guards only)
  --no-sandbox    Accepted for compatibility; OMP runs locally when image is unset
  --summary-fd N  Write summary NDJSON records to inherited fd N

WORKFLOW:
  1. Load config from .loop/yoke.conf
  2. Backup protected files (protocol.md, plan.md, judge.md, yoke.conf)
  3. Per brute attempt:
     a. Restore protected files, preserve verdict and guard feedback
     b. Run plan loop (stages + guards until DONE)
     c. Invoke judge (fresh OMP session, zero context)
     d. On FAIL or judge invocation error, reset STATUS and retry
  4. Exit on PASS or after max-judge-failures FAILs in a row for the same FAILURE-ID

A FAIL verdict must include a stable FAILURE-ID on the next line, e.g.
FAILURE-ID: checkout:duplicate-charge. A different ID starts a new streak;
PASS clears it. Skipped checks and invalid or missing verdicts do not count.
